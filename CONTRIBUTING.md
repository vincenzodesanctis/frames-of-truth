# Contributing to Frames of Truth



Thanks for your interest in contributing! 🎉



## How to contribute



1. **Fork** the repository

2. **Clone** your fork locally

3. Create a **feature branch** (`git checkout -b feature/amazing-feature`)

4. Make your changes

5. **Commit** with a clear message

6. **Push** to your fork

7. Open a **Pull Request**



## What we're looking for



- Bug fixes

- New features (check the Issues tab)

- Documentation improvements

- Translations for new languages

- UI/UX improvements



## Code style



- **Kotlin**: 4 spaces, no tabs

- **Python**: PEP 8

- **JavaScript**: 4 spaces, consistent semicolons

- **CSS**: follow the existing structure



## Never commit API keys



API keys must be entered by the user at runtime via the in-app settings.

Use empty strings in `app.py`.



## Questions?



Open an issue or start a discussion. We're friendly! 😊
