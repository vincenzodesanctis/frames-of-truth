⚙️ API Keys

Inserisci le tue chiavi API manualmente qui sotto, oppure importale da un file .txt. Se lasci un campo vuoto, verrà usata la chiave di default.

Formato del file .txt (clicca per aprire)

Il file deve essere un semplice testo con una chiave per riga nel formato NOME_CHIAVE=valore. Esempio:

GROQ_API_KEY=gsk_xxxxxxxxxxxxx
GEOAPIFY_API_KEY=db45168dxxxxxxxxxxxx
GEMINI_API_KEY=AIzaSyxxxxxxxxxxxxx
HF_TOKEN=hf_xxxxxxxxxxxxx
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxx

• Le righe che iniziano con # sono ignorate (utili per commenti).
• I campi mancanti restano invariati.
• Il riconoscimento è automatico: groq, geoapify, gemini, hf/hugging, openrouter.

Ottienila su console.groq.com/keys
Ottienila su myprojects.geoapify.com
Ottienila su aistudio.google.com/apikey
Ottienilo su huggingface.co/settings/tokens
Ottienila su openrouter.ai/keys
